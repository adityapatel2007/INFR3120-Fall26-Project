
# StudentWallet

StudentWallet is a student expense tracking web application developed for INFR3120 – Web and Scripting Programming.

## Features

- Add expenses with a name, amount, category, date, and description
- View recorded expenses in a dashboard
- Track total spending and expense statistics
- Store expense information using MongoDB
- Responsive navigation and user interface

## Technologies Used

- HTML and CSS
- JavaScript
- Node.js
- Express.js
- EJS Templates
- MongoDB and Mongoose

## Running the Project

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Create a `.env` file containing your `MONGO_URI` connection string.
4. Run `npm start`.
5. Open `http://localhost:3000`.
